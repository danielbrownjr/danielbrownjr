## On the workbench

### [BadgHer — Badger? I hardly knew her!](https://github.com/thetechbenders/badger-i-hardly-knew-her)

A photo badge, digital business card, and QR-linked project portfolio for Pimoroni's e-paper Badger boards, built with native C/C++. Supports RP2040 and RP2350 targets; hardware validation is documented per board and firmware revision.

### [DragonBreath](https://github.com/danielbrownjr/DragonBreath)

Open ESP32-C3 firmware for the BIGTREETECH Panda Breath chamber heater, with local web control and printer/home-automation integrations. Reverse-engineered heater and fan control has been validated on V1.0 and V1.0.1 boards; other revisions remain untested.

### [ChaoN-USB](https://github.com/thetechbenders/chaon-usb)

The Chaotic Neutral HID: experimental ESP32-S3 USB keyboard firmware with an on-device microSD script browser and deliberate arm/run controls. A specific firmware candidate has documented physical acceptance with outstanding fault-injection checks; it is not production-qualified.

### [Portcullis](https://github.com/thetechbenders/portcullis)

A self-hosted Linux captive-portal gateway project built with Go and nftables, exploring timed guest access and network isolation. The integrated demo runs in disposable network namespaces; physical gateway deployment remains unvalidated.

### [iCUE Spotify Integration](https://github.com/danielbrownjr/iCue-Spotify-Integration)

A touch-friendly Spotify playback and actual-queue widget for the Corsair XENEON EDGE, backed by a local Windows companion. Core playback controls and the v0.1.3 queue-jump behavior have real-device acceptance; newer visual refinements have separate verification limits.

### [BandiC5](https://github.com/danielbrownjr/BandiC5)

C5 Bandit is a pocket 2.4/5 GHz Wi-Fi RF scout for an ESP32-C5 display board, with a live dashboard, session logging, and read-only web observability. The RF dashboard is physically validated; later firmware features remain under active development.
